# Network Diagnostic Tool

A Python-based network diagnostic tool designed for basic NOC operations.

## Features

- Ping multiple hosts
- Detect UP, DOWN, TIMEOUT and HOST NOT FOUND states
- Measure packet loss
- Measure average latency
- Assess basic network health
- Generate a console-based NOC report
- Export diagnostic results to CSV

## Technologies

- Python 3.13
- Python Standard Library
- subprocess
- csv

## How to Run

Run the application with:

```bash
python main.py
